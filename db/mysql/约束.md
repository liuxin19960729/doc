# 约束
## 常见的约束
```
primary key 主键 唯一 
unique 唯一 防止重复
not null 不为空
default 设置默认值
CHECK 检查是否满足条件
foregin key外检 
unsigned 不允许设置为负数
auto_increment 自增

unique key name (column1,column2....)
```
### unique 和 primary key
```
1.都不允许重复
2.primary 不允许 NULL,unique 允许为NULL
    note:在Mysql NULL 为缺省值或未知值 即使设置了unique 也可以村子多个NULL

3.每张表 只能存在一个primary key ,但可以存在多个unique 


``` 

### CHECK
```sql

 CONSTRAINT chk_player_level CHECK (level >= 1)

 or level INT NOT NULL CHECK (level >= 1)

note:
MySQL 8.0.16 及以上：真正执行 CHECK。
MySQL 8.0.15 及以前：语法可能被接受，但约束不会被真正执行。

```
