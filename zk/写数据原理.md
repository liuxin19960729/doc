# 写数据原理
```
zk 核心 只要有半数以上同步到最新数据就可以对外提供服务
```

## 客户端之写入请求给leader
```
1.leader 接收到数据 先将自己写入最新的数据
2.在将写入的数据发送给follower,
3.follower 如果写入了则会给leader 发送ack
4.leader 接收ack+ 自己数量超过总服务器数量一半,则leader 返回客户端,告诉客户端写入成功
```
## 客户端之写入请求给follower
```
1.client 写数据请求给lollower1 (client follower1 建立连接)
2.fllower1 没有写权限 将数据 转给leader
3.leader 拿到数据 将自己数据写入更新 然后在给所有follower 发送写入数据请求
4.follower 接收到leader 的写入数据请求并且将数据写入,给leader 发送ack 告诉leader 写入成功
5.leader 接收到了ack 并且 加自己 计算是超过总服务器数量的一半,超过发送 ack 给 follower1 告诉follower1 写入成功
6.follower1 返回给客户端告诉数据写入成功
```
