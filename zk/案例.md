# 案例
## 服务器动态上下线
```
zk 集群
  创建 /servers 路径


服务器1
  zkClient create -e -s /servers  ip 

服务器2
  zkClient create -e -s /servers  ip 

.....



客户端端 监听 zkClient ls -w /servers
  监听服务器上下线(游戏服务器和zk 之间创建的临时节点 断开连接节点删除)


```

## 分布式锁
```
zk 集群
    创建 /locks 路径


1.每个客户端要想获取到锁 需要到zk 创建一个 临时顺序 节点
2.客户端自己的顺序是否是当前/locks 下的最小顺序 如果是最小顺序那么自己就获取到锁
3.如果自己不是最小顺序那么监听自己前一个顺序节点
4.获取到锁之后,做完业务,delete节点释放锁,监听它的节点收到通知 重复步骤2





note:
idea debug 模式调试 即使我们没有执行zk delete node 的命令 也有可能将节点删除
是因为客户端和服务器之间存在心跳检测 如果debug 断点 就不会回复服务器心跳 服务认为客户端连接断了自己将临时节点删除
```
