# 定时器
## 应用
```
处理延时任务

运用场景
1.心跳
2.倒计时
......


```
## 定时器的触发方式
```
1.网络事件和定时事件在一个线程中处理


网络事件+定时事件都是异步

epoll_wait select  epoll 最后一个参数都是timeout

io 多路复用阻塞收集事件和等待时机



开源框架使用该种方式
    1.单reactor redis
    2.多reactor memcached nginx



使用该种方式特征
    1.适合定时任务比较少(定时任务造成网络响应慢)


2.网络事件和定时事件在不同线程中处理
  
适合大量定时任务

怎么处理?
    1.usleep(timer) 休眠
    2.通常采用的数据结构是时间轮
    3.加锁粒度比较小

note:
    定时线程不执行任务 只通过时间轮做检测,然后将其插入队列或信号让其他线程执行


```
