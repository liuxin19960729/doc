## 线程池原理
```
模型:生产消费模型


生产者线程 --> 队列 --> 消费者线程(线程池)


队列:
    元素=任务上下文+任务执行函数



线程池 线程
   1.取出任务
   2.执行任务
   3.线程调度  mutex lock + condition
        任务从无到有
            唤醒线程
        任务从有到无
            线程睡眠



平衡选择 
    1.耗时选择
       1.1
            io.密集型   (CPU*2+2)
       1.2 
            计算密集型 (CPU)




```
