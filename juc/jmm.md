# JMM
```
作用:屏蔽不同操作系统和不同CPU架构的差异性
     JMM 来实现线程和内存抽象关系

```
### JMM 特性
```
1. 可见性
      修改共享变量
        1.load 变量到自己的工作内存
        2.在工作内存中修改变量
        3.store 到共享内存
    线程之间无法直接访问对方的工作内存    
    线程工作内存刷回到主内存的时机是不确定的

2. 原子性
3. 有序性(指令重排序)
   编译器和和处理器不破坏依赖性的情况下允许指令重排
   为了提升性能 编译器和处理器通常会对指令进行重排序
   指令重排只能保证单线程语义一致,不能保证多线程语义一致


底层的总线嗅探就机制和缓存一致性协议 
    当我们将数据写入到主内存 总线嗅探机制就能检测到 然后通知其他处理器 数据已经更新 其他处理器从主内存中读取数据


happens before 总原则
如果一个操作happens-before 另一个操作,那么第一个操作的执行结果将对第二个操作可见,
两个操作之间存在happens-before关系,并不意味着前一个操作必须要在后一个操作之前执行

两个操作之间存在着happens-before关系,不代表必须要按happens-before关系前后执行,如果重排序之后结果和happens-before关系一至，那
这种重排序并不违法
```
